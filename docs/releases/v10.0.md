# ColorOS特性补全 v10.0

10.0 大版本：改名、晕动秒开、二级控制页与文案整理。

## 主要更新

- 模块更名为 **ColorOS特性补全**。
- 晕动桥接改为开机后重试注册 SettingsObserver；在系统或 WebUI 中打开晕动开关，约 1 秒内接管传感器，不再等待 30 秒轮询。
- WebUI 新增 **晕动控制** 二级页：
  - 实际显示开关与桥接状态
  - 强度、纵向增益、触发阈值步进调节
  - 柔和 / 标准 / 强效预设
  - 恢复默认参数
- 主页晕动项改为二级页入口，不再把实际开关混在总开关卡片里。
- 清除“已移除：满血快充…”等历史增删文案，删除刷新率只读区；重写动画、模糊、AOD、手势、游戏与实验功能的说明。
- KSU 模块简介、README、`module.yaml` 与 CI Release 名称同步更新。

## 晕动参数范围

| 参数 | 范围 | 默认 |
|---|---|---|
| 强度 `motion_cues_gain` | 0.4–2.0 | 1.0 |
| 纵向增益 `motion_cues_gain_y` | 1.0–4.0 | 2.5 |
| 触发阈值 `motion_cues_gate` | 0.02–0.20 | 0.08 |

## 升级提示

桥接 APK 已更换签名。从 9.x 覆盖升级时，如果开机日志出现 `bridge: update failed`，说明旧桥接无法原地覆盖：

1. 卸载旧的 `AntiDizzy Bridge`；
2. 安装模块内 `files/AntiDizzyBridge.apk`；
3. 在 LSPosed 中重新启用并勾选“系统框架”；
4. 重启。

LSPosed 配置可能随卸载被清除，需要重新勾选作用域。

## 安装

下载 zip 后在 KernelSU 管理器中安装并重启。晕动功能需要 LSPosed；首次启用后，在“晕动控制”二级页手动打开显示开关。
