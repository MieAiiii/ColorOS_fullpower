# ColorOS特性补全 v10.1.1

10.1.1 是 10.1 的 KernelSU 门户校验修复版，功能与 10.1 完全相同。

## 修复内容

- `module.prop` 的 `versionCode` 键名由错误的 `versioncode` 改为 KernelSU 规范要求的 `versionCode`。
- 修复 KernelSU Modules 门户同步检查错误：
  `prop-missing-field: module.prop is missing a non-empty "versionCode"`。
- 版本提升到 `10.1.1 / 1002`；模块 ID `coloros_fullpower` 不变。
- CI 增加 `^versionCode=` 元数据检查，后续发版不会再漏掉大小写。

## 10.1 功能回顾

- 运行时探测 ColorOS 主版本、Settings 键、PQ 属性与晕动桥接安装状态。
- `ADAPT_MODE` 支持 `auto` / `compat` / `full`；WebUI 可切换适配策略。
- 只写当前系统存在的 Settings/PQ 键，不创建假开关；兼容模式隐藏实验项。
- 晕动控制仍在 WebUI 二级页，参数与开关逻辑不变。

## 升级提示

- 10.1 → 10.1.1 可直接覆盖安装，桥接 APK 签名未变。
- 10.0 或 9.x 升级仍按原说明处理；9.x 若提示桥接签名冲突，先卸载旧桥接再安装模块内 APK，并在 LSPosed 重新勾选“系统框架”。
- 若 KernelSU 门户仍显示旧的同步错误，在“我的模块”里点“立即同步”，等待几分钟刷新。

## 验证

- `bash -n`、ShellCheck、WebUI JS 语法与 `tools/validate_webui.py` 通过。
- `tools/adapt_mock_test.sh` 的 ColorOS 17 全量 / 16 精简 / 17 残缺场景通过。
- 10.1.1 未做真机复测；手机在发版前已断开，真机表现以实际机型为准。
